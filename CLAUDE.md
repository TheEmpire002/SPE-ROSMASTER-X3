## Working language

We work in **English**. That covers your replies and progress updates in
the chat, code (identifiers, comments, docstrings, log messages), tests,
docs, the project log, commit messages and PR descriptions, and any new
names for packages, modules, classes, functions or config constants. When
porting older German code, translate it as you go.

The only exceptions are the ones listed under "Language" in AGENTS.md:
text that users see (web app, alerts, `"text"`/`"grund"`/`"hinweis"`,
spoken sentences, speech commands) stays German, and existing protocol/API
names stay unchanged.
