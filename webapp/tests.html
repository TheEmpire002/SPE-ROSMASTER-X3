Hochladen einrichten (einmalig, GitHub-Token)
  1. Auf GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → nur dieses Repository.
  3. Permissions → Repository permissions → Contents: Read and write. Sonst nichts. Ablaufdatum setzen (z. B. Projektende).
  4. Am Roboter (Tastatur und Bildschirm oder per Terminal) speichern: 
    mkdir -p ~/.rosmaster
nano ~/.rosmaster/github_token     # Token einfügen, speichern
chmod 600 ~/.rosmaster/github_token
  5. Seite neu laden: Oben steht dann „Token vorhanden“. Der Server muss dafür nicht neu starten.

Der Roboter schreibt nur auf den Branch testdaten; sein eigener Code-Stand bleibt unberührt. Das Token verlässt den Roboter nur Richtung GitHub und wird nie angezeigt.
